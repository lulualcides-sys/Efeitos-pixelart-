# Checklist de revisão — HnS-extract

Preencha para **cada captura/importação** antes de classificar seu conteúdo ou considerar qualquer compartilhamento.

- [ ] Fonte exata registrada (projeto, versão, gravação e instante).
- [ ] Captura feita com acesso legítimo e uso local permitido.
- [ ] Autor e direitos identificados; permissão de redistribuição verificada, se aplicável.
- [ ] Categoria correta: `projectiles`, `impacts`, `contact`, `area`, `ui` ou `bosses`.
- [ ] Nome, slug e versão sem duplicação.
- [ ] Frames ordenados, FPS e duração coerentes (sem quadros congelados acidentais).
- [ ] Ponto de emissão, trajetória e contato diferenciados.
- [ ] Dano visual ocorre no contato, não na aproximação.
- [ ] Dispersão/limpeza de partículas e quadro final conferidos.
- [ ] Animação visualizada em loop e pausada na galeria.
- [ ] Fundo do vídeo identificado; **não** descrever como PNG transparente se houver cenário.
- [ ] Chroma key, se usado em pesquisa posterior, revisado contra artefatos de borda.
- [ ] Áudio, marcas, sprites e demais materiais de terceiros não publicados indevidamente.
- [ ] Comparação com biblioteca Torre 2 e cliente-base realizada antes de propor qualquer efeito novo.
- [ ] Material **não** integrado ao Torre 2 sem autorização e testes de regressão.

## Registro de avaliação sugerido

| Campo | Valor |
|---|---|
| ID | `categoria/slug` |
| HnS versão/trecho | Não preenchido |
| Tipo de efeito | Não preenchido |
| Fonte local | Não preenchido |
| Arquivo original (SHA-256) | Gerado para vídeos/GIFs |
| FPS / quadros / dimensão | Confirmar manualmente |
| Fundo/transparência | A verificar |
| Procedência e licença | A verificar |
| Status | `private-review` |
| Qualidade de impacto | Não avaliada |
| Liberado para repositório público? | **Não**, até prova de direitos |
