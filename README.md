# Efeitos Pixel Art — Biblioteca VFX

Biblioteca independente de efeitos originais para projetos em pixel art, incluindo o Pokémon Torre 2.

## Estrutura
- `effects/slash/archive/v1/`: preservação dos seis protótipos anteriores.
- `effects/slash/lateral/v2/`: seis novas versões com cortes laterais horizontais (em revisão).
- `labs/`: visualizadores animados e teste real Phaser/WebGL.
- `src/`: módulo de integração opcional; os efeitos não alteram dano nem gameplay.
- `tests/`: verificações de integridade dos sprites e navegador.
- `docs/`: regras de arte e aprovação.

**Regra:** nenhum efeito entra automaticamente na batalha ou substitui um VFX aprovado. A biblioteca serve para criação, iteração e aprovação visual.

**Autoria dos sprites:** novos VFX desenhados para este projeto. Nenhuma arte de terceiros ou frame do vídeo de referência é redistribuído. Licenciamento de redistribuição reservado à decisão do proprietário.
